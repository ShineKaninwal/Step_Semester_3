📚 Week 01
📝 Week 01 - Practice Problems
The Week 01 practice problems focus on Java fundamentals including loops, arrays, strings, conditional statements, random number generation, recursion, searching, and formatted output.
1. Rock-Paper-Scissors Game
A Rock-Paper-Scissors game where the computer generates a random choice and the player's choice is compared against it.

Concepts: Random Number Generation, Conditional Logic, Loops, Arrays, Counters, Statistics
2. Palindrome Checker - 3 Approaches
Checks whether a string is a palindrome using iterative, recursive, and character-array approaches.

Concepts: String Traversal, Iteration, Recursion, Character Arrays
3. BMI Calculator for a Team
Calculates BMI for multiple team members and displays the results in a formatted table.

Formula:

BMI = weight / (height × height)

Concepts: Arrays, Arithmetic Operations, Loops, Conditional Statements, Formatted Output
4. First Non-Repeating Character
Finds the first character in a string that occurs only once.

Concepts: Character Frequency, String Traversal, Arrays, HashMap
5. Reverse Customer Name
Reverses a customer name using character traversal.

Concepts: Strings, Character Arrays, Methods, Loops

📚 Week 10
The Week 10 work is organized on the feature/session-10 branch, with Practice-Problems and Assignment as separate top-level folders.
📝 Week 10 – Practice Problems
1. Bank Account Withdrawal System
Models savings and current bank accounts with different withdrawal restrictions. Savings accounts must retain a minimum balance of 1000; current accounts may use an overdraft of up to 5000. Withdrawal requests are accepted or rejected according to the account type.

Concepts: Inheritance, method overriding, encapsulation, input validation, account lookup.
2. Campus Vehicle Pass System
Registers bikes, cars, e-bikes, and e-cars, calculates their yearly pass fees, and permits charging-bay bookings only for electric vehicles.

Concepts: Inheritance, interfaces, polymorphism, type-specific behavior.
3. Student Club Registration Management
Stores unique student registrations by roll number, rejects duplicates even when a different object instance is supplied, and checks membership.

Concepts: HashSet, equals(), hashCode(), object equality, uniqueness.
4. Class Marks Grid Analysis
Uses a two-dimensional marks grid to calculate each student's total, subject-wise averages, and the class topper.

Concepts: 2D arrays, nested loops, totals, averages, formatted output.
5. Payroll Register System
Calculates pay for full-time, part-time, and intern staff, produces readable payslips, and identifies the top earner.

Concepts: Inheritance, polymorphism, method overriding, arrays of objects, toString().
📌 Week 10 – Assignment
These problems implement linked-list operations with custom node classes rather than java.util.LinkedList.
1. Priority Token Insertion
Implements addFirst, addLast, and insertAt(index, token) in a singly linked list.

Complexity: addFirst O(1); addLast O(n) without a tail pointer (O(1) with one); insertAt O(n) generally.
2. Cancelled Orders Cleanup
Implements removeAll(head, code) to remove every occurrence of an order code, including matches at the head.

Complexity: O(n) time and O(1) additional space.
3. Reverse the Queue
Reverses a singly linked list in place by changing node links without creating new nodes.

Complexity: O(n) time and O(1) additional space.
