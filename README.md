# 📚 Week 01

## 📝 Week 01 - Practice Problems

The Week 01 practice problems focus on Java fundamentals including loops, arrays, strings, conditional statements, random number generation, recursion, searching, and formatted output.

### 1. Rock-Paper-Scissors Game

A Rock-Paper-Scissors game where the computer generates a random choice and the player's choice is compared against it.

**Concepts:** Random Number Generation, Conditional Logic, Loops, Arrays, Counters, Statistics

### 2. Palindrome Checker - 3 Approaches

Checks whether a string is a palindrome using iterative, recursive, and character-array approaches.

**Concepts:** String Traversal, Iteration, Recursion, Character Arrays

### 3. BMI Calculator for a Team

Calculates BMI for multiple team members and displays the results in a formatted table.

**Formula:**

`BMI = weight / (height × height)`

**Concepts:** Arrays, Arithmetic Operations, Loops, Conditional Statements, Formatted Output

### 4. First Non-Repeating Character

Finds the first character in a string that occurs only once.

**Concepts:** Character Frequency, String Traversal, Arrays, HashMap

### 5. Reverse Customer Name

Reverses a customer name using character traversal.

**Concepts:** Strings, Character Arrays, Methods, Loops

# 📚 Week 06

## 📝 Week 06 - Category B Assignment

The Week 06 assignment focuses on applying Java OOP concepts to a **gym membership management system**.

The problems cover inheritance, constructor reuse, polymorphism, method overriding, static members, encapsulation, access control, arrays, defensive copying, `instanceof`, and practical object modelling.

---

### 🏋️ Problem 01 - Gym Membership Foundation & Batch Trial Sign-up Validator

Builds a basic gym membership model using `GymMember` and `PremiumMember`.

The program validates membership IDs and monthly fees and demonstrates inheritance through the premium membership class.

**Files:**

```text
GymMember.java
PremiumMember.java
```

**Concepts Covered:**

* Classes and Objects
* Constructors
* Inheritance
* `super`
* Constructor Validation
* Method Overriding
* Exception Handling
* Batch Validation

---

### 🏋️ Problem 02 - Three Tiers of Gym Membership

Creates multiple gym membership types using inheritance and polymorphism.

The program demonstrates different membership behaviours through:

* `GymMember`
* `PremiumMember`
* `EliteMember`
* `GroupClassMember`

Each subclass provides its own implementation of membership information and session attendance.

**Files:**

```text
GymMember.java
PremiumMember.java
EliteMember.java
GroupClassMember.java
```

**Concepts Covered:**

* Inheritance
* Polymorphism
* Method Overriding
* Constructor Reuse
* `super`
* Base Class References
* Runtime Method Dispatch
* Static Methods
