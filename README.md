# 📚 Week 01

## 📝 Week 01 - Practice Problems

The Week 01 practice problems focus on Java fundamentals including loops, arrays, strings, conditional statements, random number generation, recursion, searching, and formatted output.

### 1. Rock-Paper-Scissors Game

A Rock-Paper-Scissors game where the computer generates a random choice and the player's choice is compared against it.

**Concepts:** Random Number Generation, Conditional Logic, Loops, Arrays, Counters, Statistics

### 2. Palindrome Checker - 3 Approaches

Checks whether a string is a palindrome using iterative, recursive, and character-array approaches.

**Concepts:** String Traversal, Iteration, Recursion, Character Arrays

### 3. BMI Calculator for a Team

Calculates BMI for multiple team members and displays the results in a formatted table.

**Formula:**

`BMI = weight / (height × height)`

**Concepts:** Arrays, Arithmetic Operations, Loops, Conditional Statements, Formatted Output

### 4. First Non-Repeating Character

Finds the first character in a string that occurs only once.

**Concepts:** Character Frequency, String Traversal, Arrays, HashMap

### 5. Reverse Customer Name

Reverses a customer name using character traversal.

**Concepts:** Strings, Character Arrays, Methods, Loops

Week 10 work is organized on the [`feature/session-10`](https://github.com/ShineKaninwal/Step_Semester_3/tree/feature/session-10) branch into two top-level folders: `Practice-Problems` and `Assignment`.

## 📝 Week 10 – Practice Problems

| # | Problem | Main concepts |
|---|---|---|
| 1 | Bank Account Withdrawal System | Inheritance, method overriding, withdrawal rules |
| 2 | Campus Vehicle Pass System | Interfaces, inheritance, polymorphism |
| 3 | Student Club Registration Management | `HashSet`, `equals()`, `hashCode()` |
| 4 | Class Marks Grid Analysis | 2D arrays, averages, totals |
| 5 | Payroll Register System | Polymorphism, arrays of objects, `toString()` |

### Practice problem descriptions

1. **Bank Account Withdrawal System:** Savings accounts must maintain a minimum balance of 1000; current accounts can overdraw to -5000.
2. **Campus Vehicle Pass System:** Calculates yearly fees for bikes, cars and electric variants; only electric vehicles can book charging bays.
3. **Student Club Registration Management:** Rejects duplicate roll numbers, even when the student is represented by a different object instance.
4. **Class Marks Grid Analysis:** Computes student totals, subject averages and the topper from a three-subject marks grid.
5. **Payroll Register System:** Calculates full-time, part-time and intern pay, prints payslips and finds the top earner.

## 📌 Week 10 – Assignment

| # | Problem | Main concepts |
|---|---|---|
| 1 | Priority Token Insertion | Singly linked list, `addFirst`, `addLast`, `insertAt` |
| 2 | Cancelled Orders Cleanup | Singly linked list, remove all matching nodes |
| 3 | Reverse the Queue | In-place linked list reversal |
| 4 | Train Coaches Both Ways | Full problem specification pending verification |
| 5 | Round-Robin Game Turns | Full problem specification pending verification |

**Complexity:** Priority insertion: `addFirst` O(1), `addLast` O(n) without a tail reference (O(1) with one), `insertAt` O(n). Removing matching nodes and reversing a list each take O(n) time and O(1) additional space.
